# 2026-11-01 体验优化上线记录

已部署至 https://learnwise.waywise.tech 。

## 本轮改动

- 首页在当前标签页的 sessionStorage 保留主题和目标，登录回来可继续填写；成功创建后清理草稿，超过 24 小时的草稿不恢复。
- 学习页固定底栏展示下一个推荐知识点、当前档位及页面是否准备好；每 15 秒在可见标签页检查状态，不需要等闯关结束才能找到入口。查询接口只读，不触发额外生成。
- 手机尺寸优化按钮点击区域、学习页底部留白、顶部步骤导航、长内容换行，以及星图搜索输入与面板安全区域。
- 本次同时上线此前完成的首页预生成、后台补齐、任务优先级、预算暂停、保存失败重试等修复。

- 真实 Chrome 在 390 × 844 手机尺寸检查首页、知识地图、学习页和星图，在 1280 × 900 桌面尺寸检查学习页，均未出现横向溢出或未捕获的 JavaScript 错误；检查了登录跳转后草稿恢复、下一页准备状态与固定入口。此项是桌面 Chrome 的手机尺寸模拟，未使用实体手机。

- 部署后通过线上 HTTPS 验证首页、学习页、星图、健康检查和下一页状态接口。systemd 状态为 active/running，NRestarts=0。
