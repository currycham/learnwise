# 学习页 JSON 结构（schema_version 1）

模型只输出这份 JSON，页面由 `app/templates/learn.html` 渲染。样例在 `fixtures/`，校验用 `python3 -m app.schema fixtures/*.json`。

一页 = 一个知识点 × 一个档位，约 30 分钟。

文字字段里允许的轻量标记：`**加粗**`、`` `行内代码` ``、```` ```代码块``` ````（代码块只在 example / practice 里用），段内换行写 `\n`。其它 HTML 一律按纯文本显示。

```jsonc
{
  "schema_version": 1,
  "concept": {
    "name": "知识点名称",
    "aliases": ["英文名或常见别名"],
    "domain": "所属领域，如：概率论",
    "level": "启蒙 | 进阶 | 深入",
    "one_line": "一句话说清它是什么，≤40字",
    "minutes": 30
  },

  // 领域地图里和本页相关的一小块：用于“地图定位”
  "map": {
    "stages": [
      {"name": "入门", "nodes": ["知识点A", "知识点B"]},
      {"name": "进阶", "nodes": ["本知识点", "知识点C"]},
      {"name": "深入", "nodes": ["知识点D"]}
    ],                                   // 3 个阶段，共 6–12 个节点，必须包含本知识点
    "prereqs": ["本页假定你已懂的知识点，0–3 个，须出现在 stages 里"],
    "unlocks": ["学完能接着学的，0–3 个，须出现在 stages 里"],
    "why_here": "它在这个领域里为什么重要、处在什么位置，≤80字"
  },

  "hook": {
    "type": "story | paradox | problem",
    "title": "≤20字",
    "text": "开场故事/悖论/真实问题，150–300字，结尾抛出本页要回答的问题"
  },

  // 学之前先猜，答错没关系
  "predict": [
    {"q": "题干", "options": ["A", "B", "C"], "answer": 0, "why": "学完再看的解释，≤80字"}
  ],                                     // 1–2 题，3–4 个选项

  "chunks": [
    {
      "title": "知识块标题",
      "one": "一句话核心，≤40字",
      "core": ["讲解段落，2–4 段，每段 60–150 字"],
      "analogy": "一个类比，≤100字（深入档可以为空字符串）",
      "example": "一个具体例子，60–200字",
      "diagram": null,                   // 可选，见下方“图”
      "myth": "常见误区 + 正确理解，≤120字，不要以“误区：”开头",
      "recall": [{"q": "主动回忆题", "a": "参考答案"}]   // 正好 2 题
    }
  ],                                     // 3–5 块

  // 启蒙：worked 为主；进阶：worked → faded → solo；深入：open 为主
  "practice": [
    {"type": "worked | faded | solo | open", "q": "题目", "steps": ["步骤（worked 全给；faded 部分步骤写成 ___ 让人补）"], "a": "答案或参考思路"}
  ],                                     // 1–3 题

  // 深入档必填，其他档可省略：流派之争 / 前沿 / 边界
  "debates": [
    {"question": "争议的问题", "views": [{"who": "谁/哪一派", "claim": "主张，≤120字"}], "status": "目前的共识程度，≤80字"}
  ],

  "quiz": [
    {"q": "题干", "options": ["A", "B", "C", "D"], "answer": 2, "why": "≤60字", "chunk": 1, "kind": "本页 | 前置 | 迁移"}
  ],                                     // 8 题；chunk 从 1 开始；答案位置分布均匀、无规律；至少 1 题 kind=前置，至少 2 题 kind=迁移

  "feynman": {
    "prompt": "请你用自己的话讲给一个……听：……",
    "key_points": ["讲清楚必须覆盖的要点，3–5 条"],
    "common_gaps": ["大家最常讲漏或讲错的地方，2–3 条"]
  },

  "transfer": {
    "prompt": "它可以用在你的哪件事上？",
    "template": "填写模板，多行用 \n 分隔"
  },

  // 是否值得做播客：由模型判断，worth=false 时写理由
  "podcast": {"worth": true, "reason": "≤60字", "outline": ["worth=true 时给 3–5 个聊天要点"]},

  "tutor": {"style": "苏格拉底式追问的风格描述，≤60字", "starters": ["学习者可能问的问题，3 个"]},

  "confidence": {"level": "high | medium | low", "notes": "哪些内容依据充分，哪些是简化"},
  "sources": [{"title": "来源", "url": "只放确定存在的链接，拿不准就只写书名不写 url"}]
}
```

## 图

`diagram` 只允许三种结构化类型，由模板画，不让模型直接写 SVG：

```jsonc
{"type": "flow", "caption": "图注", "steps": ["第一步", "第二步", "第三步"]}           // 2–6 步，横向箭头
{"type": "compare", "caption": "图注", "columns": [{"title": "A", "items": ["…"]}, {"title": "B", "items": ["…"]}]}  // 2–3 列
{"type": "bars", "caption": "图注", "unit": "单位", "bars": [{"label": "…", "value": 12.5}]}  // 2–8 根，值非负
```

## 三档的写法差异

| | 启蒙 | 进阶 | 深入 |
|---|---|---|---|
| 开场 | 故事 | 问题或悖论 | 悖论或未解问题 |
| 术语 | 尽量少，出现就用大白话解释 | 精确定义 | 默认读者懂基础术语 |
| 类比 | 每块都有 | 每块都有 | 可以没有 |
| 练习 | worked | worked → faded → solo | open |
| debates | 无 | 可选 | 必填，至少 2 个 |
| 闯关 | 理解为主 | 理解 + 计算/操作 | 判断、辨析、边界情况 |
